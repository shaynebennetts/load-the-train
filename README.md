# Load the train

Project 1, Basic Skills for Experimentalists (TIGP 2026).

A physics-based freight-train loading game: a locomotive and 20 cars start 1 km
from a grain chute. The player controls locomotive throttle and brake, and opens
and closes the chute. The aim is to load fast while keeping every car above 95 %
full and total grain loss under 1 %.

- `app/index.html` — the game, a single self-contained file.
- `index.html` — the project website (root).
- `SPEC.md` / `PLAN.md` — specification and build plan.

Developer notes live here; the project website is the reader-facing document.
