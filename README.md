# Load the train

Project 1, Basic Skills for Experimentalists (TIGP 2026).

A physics-based freight-train loading game: a locomotive and 20 cars start 30 m
from a grain chute. The player has one signed throttle (there is no brake --
retardation is regenerative) and opens and closes the chute. The aim is to load
fast while keeping every car above 90 % full and total grain loss under 1 %.

- `app/index.html` — the game, a single self-contained file.
- `index.html` — the project website (root), published with GitHub Pages.
- `favicon.svg`, `images/` — assets for that page only.
- `SPEC.md` / `PLAN.md` — specification and build plan.

Developer notes live here; the project website is the reader-facing document.
